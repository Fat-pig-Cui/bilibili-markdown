# Markdown 全功能导入验收

## 导入对象

选择整个 `examples/feature-coverage/` 文件夹，导入 `article.md`。文件夹含一份文档和一张本地 PNG；图片上传到 B 站，使用独立空白测试稿，不要覆盖正式文章。当前文档以脚本支持的语法编写，不新增解析规则。

本示例按要求移除了下划线用例。行间公式使用独占段落的 `$$...$$`；0.2.7 会为它的段落设置 B 站原生居中属性，正文、行内公式和代码不因此居中。
