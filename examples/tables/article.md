# 表格转图片验收

表格前检查点：行内公式 $a^2+b^2=c^2$ 应继续保持原生可编辑。

## 字符样式与三种列对齐

| 左对齐字段 | 居中对齐内容 | 右对齐数字 |
| :--- | :---: | ---: |
| **粗体中文** | *斜体文本* | 123.45 |
| ~~删除内容~~ | `code_value` | 7 |
| 转义竖线 a\|b | [链接显示文字](https://www.bilibili.com/) | 0.0123 |
| 空单元格 → | | 99 |
| 中文长文本应该在单元格内部自然换行，不应越过边框或被裁掉。 | 第一行<br>第二行 | 10000 |

两表之间检查点：这里只应看到正常段落，不应多出空白行。

## 表内公式

| 名称 | 表达式 | 说明 |
| :---: | :---: | :---: |
| 二项分布 | $P(X=k)=\binom{n}{k}p^k(1-p)^{n-k}$ | 上下标不丢失 |
| 求和 | $\sum_{i=1}^{n} i=\frac{n(n+1)}{2}$ | 公式合成在图片中 |
| 普通文字与公式 | 当 $x_i^2+y_i^2=r^2$ 时 | 混排应正确换行 |

表格外行间公式仍应是原生公式并自动居中：

$$
f(x)=(x+1)^2
$$
